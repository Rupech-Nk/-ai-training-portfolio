Named Entity Recognition (NER)

Extracting Structured Information from Unstructured Text

Project: Customer Support Named Entity Recognition
Author: Rupech Nkengafack
Project Type: Independent AI Data Annotation Portfolio

1. Project Overview

This project focuses on identifying and classifying important entities within customer-support messages.

Named Entity Recognition (NER) is a natural language processing task that enables AI systems to identify specific information, such as people, organisations, locations, dates, monetary amounts and order references, within unstructured text.

The goal is to transform ordinary customer messages into structured, machine-readable information.

2. Annotation Objectives

The project aims to demonstrate the ability to:

* Identify named entities accurately.
* Apply consistent entity labels.
* Recognise entities within informal customer messages.
* Handle overlapping and ambiguous information.
* Preserve exact text boundaries.
* Review annotations for completeness and consistency.

3. Entity Categories

The following entity types will be used:

Entity	Description	Example
PERSON	Individual’s name	Sarah Johnson
ORGANIZATION	Company or institution	Amazon
LOCATION	Geographic location	Dubai
DATE	Calendar date	14 November 2026
TIME	Specific time	3:30 PM
MONEY	Monetary amount	AED 250
ORDER_ID	Order reference	ORD-78421
PRODUCT	Named product	Galaxy S25
EMAIL	Email address	sarah@email.com
PHONE	Phone number	+971501234567

4. Annotation Methodology

Each message will be reviewed to identify all relevant entities.

The annotation process will follow these steps:

1. Read the complete message to understand its context.
2. Identify all entity mentions.
3. Mark the exact beginning and ending boundaries of each entity.
4. Assign the appropriate entity category.
5. Review spelling, boundaries and label consistency.
6. Flag ambiguous or incomplete information.

5. Quality Assurance

Annotations will be checked for:

* Correct entity identification.
* Accurate text boundaries.
* Consistent label application.
* Missing or incorrectly classified entities.
* Proper handling of repeated entity mentions.
