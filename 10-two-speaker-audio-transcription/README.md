Two-Speaker Audio Transcription and Diarisation

Project Overview

This project demonstrates practical speech-to-text transcription and speaker diarisation using a 58.5-second, two-person customer-service conversation.

Tasks Performed

* Transcribed spoken dialogue using a clean-verbatim approach.
* Identified and labelled two speakers.
* Added timestamps to individual speech segments.
* Preserved natural speech patterns, repetitions and incomplete words.
* Reviewed speaker attribution and transcript consistency.

Annotation Details

* Duration: 58.5 seconds
* Number of speakers: 2
* Transcription style: Clean verbatim
* Speaker labels: Speaker 1 and Speaker 2
* Timestamp format: MM:SS.s

Files

* transcript.txt – Complete conversation transcript.
* transcription_timestamps.csv – Timestamped transcript with speaker labels.

Skills Demonstrated

Speech-to-text transcription, speaker diarisation, timestamp alignment, verbatim annotation and transcription quality control.

Project Type

Independent practical portfolio exercise.
