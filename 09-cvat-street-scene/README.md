CVAT – Street Scene Object Detection

Project Overview

A practical multi-class image annotation exercise completed using CVAT.

Annotation Task

Identified and annotated objects in a street scene using rectangular bounding boxes.

Object Classes

* Cars
* People
* Bicycles
* Trees
* Motorcycles

Skills Demonstrated

* Multi-class object detection
* Bounding box annotation
* Object classification
* Label consistency
* Visual attention to detail

Tool

CVAT – Computer Vision Annotation Tool

Independent portfolio exercise.
