# Customer Intent Classification

## Project Overview
This project demonstrates the classification of customer messages according to the reason for contacting customer support.

## Objective
To identify the primary intent behind each customer message.

## Sample Annotations

| Customer Message | Intent |
|---|---|
| I want my money back. | Refund Request |
| Where is my order? | Order Tracking |
| I can't log into my account. | Login Issue |
| Please change my delivery address. | Account Update |
| I would like to cancel my subscription. | Cancellation |

## Annotation Guidelines
- Refund Request: Customer requests money back.
- Order Tracking: Customer asks about delivery or order status.
- Login Issue: Customer experiences account access problems.
- Account Update: Customer requests changes to account details.
- Cancellation: Customer wants to terminate a service or order.

## Skills Demonstrated
- Intent classification
- Text annotation
- Label consistency
- Understanding customer requests
