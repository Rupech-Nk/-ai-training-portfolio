# Sentiment Analysis

## Project Overview
This project demonstrates how to identify and classify sentiment in customer support messages.

## Objective
To categorise customer feedback as Positive, Negative, or Neutral.

## Sample Annotations

| Customer Message | Sentiment | Reason |
|---|---|---|
| The support agent was very helpful. | Positive | Expresses satisfaction |
| I've contacted support several times with no solution. | Negative | Expresses frustration |
| My replacement will arrive on Friday. | Neutral | Provides factual information |

## Annotation Guidelines
- Positive: Expresses satisfaction or appreciation.
- Negative: Expresses dissatisfaction or frustration.
- Neutral: Contains factual information without clear emotional language.

## Skills Demonstrated
- Text classification
- Sentiment identification
- Consistent labelling
- Annotation quality control
