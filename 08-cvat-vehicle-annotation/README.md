CVAT – Vehicle Object Detection Annotation

Project Overview

A practical image-annotation exercise completed using CVAT (Computer Vision Annotation Tool).

Annotation Task

The task involved identifying and annotating all visible cars in an image using rectangular bounding boxes.

Work Completed

* Created the label Car.
* Drew bounding boxes around 14 visible cars.
* Ensured boxes covered the vehicles accurately.
* Excluded unrelated objects such as pedestrians, buses, roads and trees.

Skills Demonstrated

* Image annotation
* Object detection
* Bounding box creation
* Label consistency
* Attention to detail
* Practical use of CVAT

Tool

CVAT – Computer Vision Annotation Tool
